# Turbo C Programming

A collection of C programming exercises, practicals, and simulation-based programs developed using **Turbo C / Turbo C++ IDE**.

This repository contains programs written and executed specifically in the Turbo C environment, focusing on learning C programming fundamentals, developing logical thinking, and exploring graphical simulations using its built-in libraries.

## 🎯 Objectives

- Learn the fundamentals of C programming.
- Practise programming concepts through practical exercises.
- Understand the use of Turbo C-specific functions and libraries.
- Develop basic graphical and simulation-based programs.
- Improve logical thinking and problem-solving skills.

## ⚙️ How to Run

These programs are intended to run in the Turbo C / Turbo C++ environment.

1. Open Turbo C or Turbo C++.
2. Open the required `.c` source file.
3. Compile the program using `Alt + F9`.
4. Run the program using `Ctrl + F9`.
5. View the output in the Turbo C environment.

**Note:** Some programs use Turbo C-specific libraries and functions, such as `conio.h`, `graphics.h`, `clrscr()`, `getch()` and `initgraph()`. They may require DOSBox or a compatible environment and are not directly compatible with modern compilers such as GCC.

## 📌 Important Notes

- Programs are written specifically for the Turbo C environment.
- Graphics-based programs require the appropriate graphics library and BGI configuration.
- Source codes are maintained in `.c` format.
